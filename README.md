# GoMelsec

Go言語による三菱電機製プログラマブルコントローラ（MELSEC）通信ライブラリ。
MCプロトコル（1E / 3E / 4E フレーム、TCP / UDP、バイナリ通信）に対応し、FA現場やIoTシステムでの高信頼・高速なデータ収集・制御を実現します。

## 特徴
- **マルチフレーム対応**: 1E / 3E / 4E フレーム対応
- **マルチPLC対応**: Q/Lシリーズ、iQ-Rシリーズ、iQ-F (FX5U/FX5UJ) シリーズ、FX3 (FX3U/FX3G) シリーズ
- **高速性**: `sync.Pool` によるバッファ再利用・ゼロアロケーション指向
- **自律復旧**: 通信切断時の自動再接続、指数バックオフ付きリトライ
- **健全性監視**: ループバックテスト (0619H) によるメモリ非侵襲なヘルスチェック (Ping) & レイテンシ計測
- **豊富なAPI**: ビット・ワードの単一/一括/ランダム読み書き、型安全アクセス (Int16/32/64, Float32/64, String)、生HEX/RawBytes直接操作
